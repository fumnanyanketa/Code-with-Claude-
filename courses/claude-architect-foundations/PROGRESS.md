# My progress: Claude Certified Architect — Foundations

**North-star project — "Atlas Support":** you build **one** multi-agent system that
grows across the whole course, ending as a support agent that escalates to a
human. Build every capstone as the next component of Atlas Support.

**Daily ritual:** read the lesson, do the lab/capstone, commit + log, tick the box.

**Goal:** about one lesson a session (~30–60 min each). Andrew's advice: one hour a
day, don't cram — the concepts are new and won't stick if you rush.

**Exam target:** CCA-F · 60 questions · pass 720/72% (17 wrong allowed) · 120 min.
