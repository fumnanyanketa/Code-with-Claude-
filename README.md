## How transcripts are extracted

`extract_transcripts.py` pulls English captions (manual where available, else
auto-generated) for every video via [`yt-dlp`](https://github.com/yt-dlp/yt-dlp),
and writes two files per talk in `transcripts/<playlist>/`:

- `NN_<slug>.txt` — clean, paragraph-wrapped plain text (title/URL header)
- `NN_<slug>.timestamped.txt` — same text with `[hh:mm:ss]` cue timestamps

### Running it

```bash
pip install yt-dlp
python3 extract_transcripts.py
```

It's **resumable**: it skips videos already done and remembers which ones have no
captions (`*.nocaptions`) or were removed (`*.unavailable`), so re-runs are fast.
Status is written to `extract_summary.json`.

### Getting past YouTube's bot detection (cloud / datacenter IPs)

YouTube blocks caption requests from datacenter IPs ("Sign in to confirm you're
not a bot"). The script handles this two ways, in order of preference:

1. **Cookies (best).** Drop a Netscape-format `cookies.txt` (exported from a
   logged-in YouTube session) next to the script. An authenticated session is not
   bot-blocked, and it's fast (~2s/video). `cookies.txt` is git-ignored.
2. **No cookies — JS-challenge solver.** If there's no cookie file, the script
   falls back to yt-dlp's official EJS solver (fetched from the `yt-dlp/ejs`
   GitHub release) run via Node, using the `tv` player clients. This works but is
   slower and an aggressively-flagged IP may still be throttled.

On a residential IP, neither workaround is needed — plain `yt-dlp` just works.

### The 17 talks without captions

Some talks have no YouTube captions at all (auto-captions weren't generated). The
only way to transcribe those is from the **audio**: download with `yt-dlp`, then
run **Whisper** (e.g. Groq's free `whisper-large-v3`, or local `faster-whisper`).
That's a separate step not included here.
