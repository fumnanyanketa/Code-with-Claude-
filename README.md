## How the transcripts were produced

Two scripts, both resumable (re-running skips work already done):

- **`extract_transcripts.py`** — pulls English captions (manual, else auto) for every
  video via [`yt-dlp`](https://github.com/yt-dlp/yt-dlp). Writes `NN_<slug>.txt`
  (paragraph-wrapped plain text) and `NN_<slug>.timestamped.txt` (`[hh:mm:ss]` cues).
- **`transcribe_audio.py`** — for talks with **no** YouTube captions, downloads the
  audio (yt-dlp), splits it with ffmpeg, and transcribes via **Groq Whisper**
  (`whisper-large-v3` / `-turbo`). Needs `GROQ_API_KEY` (env or a git-ignored `.env`).

```bash
pip install yt-dlp groq imageio-ffmpeg
python3 extract_transcripts.py     # caption-based transcripts
python3 transcribe_audio.py        # audio transcription for the rest (needs GROQ_API_KEY)
```

### Notes
- **Cloud-IP bot detection.** YouTube blocks datacenter IPs. The scripts get past this
  with a `cookies.txt` (logged-in session, git-ignored) — or, without cookies, yt-dlp's
  EJS JS-challenge solver run via Node. On a residential IP neither is needed.
- **Caption vs. Whisper.** Caption-based transcripts are verbatim YouTube captions;
  Whisper ones are machine-transcribed from audio (each file's header notes its source).
- **The 2 missing talks** (Day 2 #14, #15) were removed from YouTube by the uploader, so
  no transcript can be produced.
