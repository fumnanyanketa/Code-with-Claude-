## How transcripts are extracted

`extract_transcripts.py` pulls the English captions (manual where available,
otherwise auto-generated) for every video, using [`yt-dlp`](https://github.com/yt-dlp/yt-dlp).

Each talk produces two files in `transcripts/<playlist>/`:

- `NN_<slug>.txt` — clean, paragraph-wrapped plain text (with a title/URL header)
- `NN_<slug>.timestamped.txt` — the same text with `[hh:mm:ss]` cue timestamps

### Running it

```bash
pip install yt-dlp youtube-transcript-api
python3 extract_transcripts.py
```

The script is **resumable** — it skips any video whose transcript already exists,
so you can re-run it repeatedly to fill gaps. Progress is written to `extract.log`
and a machine-readable status to `extract_summary.json`.

### Note on cloud / datacenter IPs

YouTube aggressively rate-limits and bot-blocks requests from cloud/datacenter IP
ranges ("Sign in to confirm you're not a bot"). To get past this the script:

- uses yt-dlp's official **EJS JS-challenge solver** (downloaded from the
  `yt-dlp/ejs` GitHub releases) run via a local **Node.js** runtime, and
- restricts itself to the `tv` / `tv_embedded` player clients (which return
  downloadable captions without a PO token) and paces requests slowly.

Even so, a flagged IP may block a subset of videos until its reputation recovers.
**Running the script from a residential IP (e.g. your own machine) extracts all
videos reliably and quickly**, since the bot-detection that throttles this
environment does not apply there.
